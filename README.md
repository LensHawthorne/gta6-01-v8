An original, browser-based open-world crime game set in the fictional coastal city of Solara Bay. Built for the make.fun "Make GTA 6" bounty ($1,666 USDC, 1st place $500). All city, character, vehicle, story, art, sound and music content is original — nothing from Rockstar's GTA.

## What is in the game

- 8 story missions with staged objectives
- 5-star wanted system with PCPD dispatch: named police units, helicopter
  and roadblocks
- Driving, carjacking, on-foot action, weapon wheel and combat
- Garage upgrades, crew rank and respect (RP), 3 crew abilities
- Saves (localStorage), radio, speedometer, round minimap, district
  standing, named NPC dialogue
- Dense HUD: mission panel, wanted stars, money, weapon slots, minimap
- Day beach/coast chase and night market scenes; 4 districts

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no
network requests — everything is a local file.
